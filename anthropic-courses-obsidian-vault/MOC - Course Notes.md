## How this vault is organized
- **Exams** hold the actual quiz questions and answer keys, largely as-is, but with feature/framework names linked out to their concept note instead of re-explaining them inline.
- **Concepts** are atomic: one note per idea, written once, reusable across every future course. When the same concept (e.g. a framework, a product feature) shows up in a later course, link to the existing note instead of creating a duplicate — Obsidian's backlinks panel on each concept note will then show you every exam that touches it.
- Each concept note has a **"From the lesson (fill in)"** section left blank on purpose — that's where your own notes from the actual lesson videos go, since these notes were built from public syllabi rather than the videos themselves.
- Fold the "Answer Key" heading in each exam note before attempting it (click the collapse arrow next to the heading).
