# Enterprise Search

## Definition (verified)
A shared, organization-wide way to query across every connected company data source at once (e.g. "what's our Q3 PTO policy," "who owns the Acme account") — instead of hunting across five different tools by hand.

## Key nuance
It only surfaces what's *already connected*, and access follows each person's own existing permissions — there's no backdoor access. An admin has to deliberately enable each source, so which sources get connected is worth an explicit conversation before turning it on.
