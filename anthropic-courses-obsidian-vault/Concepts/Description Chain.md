# Description Chain

## Definition (verified)
The path from a messy, real-world user need to a precise instruction an AI can actually act on. Part of the builder-specific version of [[Description]].

**Example:** "Checkout feels slow, can you fix it?" →  turned into something like: "Checkout load time exceeds 3s on mobile; profile it and propose fixes; target under 1.5s."

This step has to happen *before* a prompt gets written — skipping it is how you end up with polished output that solves the wrong problem (e.g. "make onboarding better" with no definition of what's actually broken, for whom, measured how).
