# Discernment

## Definition (verified)
Part of the [[4D Framework]]. Accurately assessing how useful — and how correct — an AI's output or behavior actually is. Critically evaluating what the AI actually produced, not just accepting it.

## Builder-specific version
For code: evaluated across several **lenses**, not just "does it run" — see [[Discernment for Code (Five Lenses)]].

For user experience: **"'it works' stops being the bar."** Functional correctness (buttons click, forms submit) is necessary but not sufficient — the real check is whether the experience matches real user mental models, is consistent with the rest of the product, and actually reduces confusion.
