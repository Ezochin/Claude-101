# Projects

## Definition (verified)
A workspace where you group related chats, files, and instructions so Claude has consistent, shared context for an ongoing piece of work. Useful anywhere the same background (brand guidelines, a contract, a client's context, a personal project) needs to inform many separate conversations instead of being re-explained or re-pasted each time.

## Why it matters
The main fix for scattered, inconsistent output across a team (or across your own chats) — centralize the shared context once instead of leaving it to live in individual people's chat histories.
