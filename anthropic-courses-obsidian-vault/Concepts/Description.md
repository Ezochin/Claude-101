# Description

## Definition (verified)
Part of the [[4D Framework]]. Effectively describing your goals so the AI produces useful behavior and output — communicating goals, constraints, and desired outputs clearly enough to get something usable back.

Being strong at Description does **not** automatically mean you're strong at [[Discernment]] — they're separate skills. You can prompt beautifully and still fail to catch a wrong answer.

## Builder-specific version
For builders, Description includes writing **[[Acceptance Tests]]** *before* any code exists: defining what "done" looks like up front gives both you and the AI a clear target, and a real way to check the result.

It also includes the **[[Description Chain]]** — turning a vague, messy, real-world need (e.g. "checkout feels slow, can you fix it?") into a precise, testable instruction *before* any prompt gets written.
