# Research (Claude Capability)

## Definition (verified)
Built for deep, multi-step questions that need Claude to investigate across several sources and return a thorough, cited answer — not just a quick single-fact lookup.

## Key nuance
Citations are a starting point for verification, not proof by themselves — the habit worth keeping is to actually open and skim the cited sources before repeating a claim somewhere higher-stakes (e.g. a board deck).
