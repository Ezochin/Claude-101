# Connectors

## Definition (verified)
Live links from Claude to outside tools and data — like Google Drive, Slack, Gmail, or a project tracker — so it can pull in real information and, in some cases, take action, instead of working only from what's typed into the chat.

## Why it matters
Extends Claude's context beyond the conversation itself. Underpins [[Enterprise Search]] (which queries across whatever's connected) and is built on the open [[Model Context Protocol (MCP)]] standard.
