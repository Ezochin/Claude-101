# Skills

## Definition (verified)
Reusable, packaged instructions (and sometimes reference files or examples) so Claude can reliably repeat a specific way of doing a task, instead of the task being re-explained from scratch — or living as tribal knowledge with one person — every time.

## Why it matters
Turns a one-off good prompt into a repeatable, shareable standard (e.g. "write in this client's voice").
