# Prompting Fundamentals

## Definition (verified)
The core "getting better results" habit taught in Claude 101: before expecting a strong answer, give Claude the task, the relevant **context** (goal, audience, constraints, desired format), and what a good result should look like — then treat the first response as a draft and **iterate** (give feedback to refine) rather than assuming the first prompt must be perfect, or abandoning the whole conversation and starting over each time.

## Core moves
- Add context: goal, audience, constraints, format
- Give an example of the output style you want
- Break a large task into smaller steps
- Treat the first response as a draft; give feedback and refine
- Claude works from what's actually in the conversation (plus connected/uploaded material) — it doesn't infer background it was never given
