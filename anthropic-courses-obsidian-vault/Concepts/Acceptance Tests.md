# Acceptance Tests

## Definition (verified)
In the builder track, tests written to define "done" *before* a single line of code exists — part of the builder-specific version of [[Description]]. Defining what "done" looks like up front gives both you and the AI a concrete target, and a real way to check the result once it exists. They don't replace [[Discernment]] — they set the bar Discernment later checks the work against.
